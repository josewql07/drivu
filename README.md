# Drivu

Página web de **Drivu**, una app de taxi para Lima que se adapta sola a quien la usa: simplifica la pantalla y agranda los botones cuando nota que a alguien le cuesta un paso. Está pensada para personas mayores y para jóvenes que recién empiezan a usar apps de taxi.

Proyecto académico del curso de Interacción Humano Computador.

- Sitio: https://josewql07.github.io/drivu/
- Prototipo: https://josewql07.github.io/drivu/app/

## Contenido

| Archivo | Qué es |
|---|---|
| `index.html` | Landing con el asistente de ayuda |
| `foro.html` | Foro de usuarios |
| `libro-de-reclamaciones.html` | Libro de Reclamaciones virtual (modo demostración) |
| `app/index.html` | Prototipo de la app (todo en un archivo; cuentas, viajes y conductores simulados en el navegador) |
| `media/` | Videos del tutorial y sus portadas |
| `icono/` | Icono de Drivu para la pestaña del navegador |

Es un sitio estático: no necesita servidor ni instalar nada. GitHub Pages lo publica desde la rama `main`, carpeta raíz.
